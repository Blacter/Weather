### Проект “Погода”

#### Суть проекта

Веб-приложение создано для отслеживания погоды в выбранных пользователем локацях.
Позволяет искать города, сохранять их и получать актуальные погодные данные через OpenWeather API.

Функции приложения:

- регистрация и аутентификация пользователей;    
- добавление локаций в базу данных;
- удаление локации из базы данных;
- поиск локация по названию;
- просмотр текущей погоды.

#### Используемые технологии

- Backend: Python, Django;
- ORM: Django ORM;
- Базы данных: PostgreSQL;
- Тестирование: unittest, Django TestCase;
- Шаблонизатор: Jinja2;
- Frontend: HTML, CSS, Bootstrap 5;
- API: OpenWeather API (получение данных о погоде), Geocoding API (поиск городов);


#### Мотивация проекта

- изучить фреймворк Django;
- получить навыки работы с Django ORM и миграциями БД в Django;
    - закрепить базовые принципы юнит и интеграционного тестирования,
с использованием unittest и средствами тестирования Django (TestCase, SimpleTestCase и др.);

  - на практике закрепить принципы аутентификации на основе механизма сессий;

#### Особенности:

  - в целях практики регистрация и аутентификация реализованы без использования встроенных возможностей Django;
  - самостоятельно реализуется механизм сессий: чтение и запись сессионных cookies происходит в слое middleware;
  - подключение чувствительных данных (ключей, паролей) происходит с помощью pydantic_settings;


#### Интерфейс приложения:

Главная страница
  - Заголовок

    -- Для неавторизованных пользователей: кнопки регистрации и авторизации
    
    -- Для авторизованных пользователей: логин текущего пользователя и кнопка Logout
    
  - Контент
    
    -- Поле ввода для поиска локации по названию
    
    -- Список добавленных локаций. Каждый элемент списка отображает название, текущую температуру и кнопку “удалить”

Страница результатов поиска локаций по названию

Переход на эту страницу осуществляется в результате заполнения поля ввода на главной странице, либо на странице результатов поиска.\

Содержимое:

  - Заголовок, такой же как на главной странице
    
  - Поле ввода для поиска по названию - такое же, как на главной странице, чтобы не возвращаться туда для каждого нового поиска
    
  - Список найденных локаций с кнопкой “добавить”. При нажатии на кнопку происходит переход на главную страницу
  
  Остальное:
  
 - Страницы с формами регистрации и авторизации
